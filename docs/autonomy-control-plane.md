# منظومة القيادة الذاتية

## الهدف

تضيف هذه الطبقة دورة تشغيل قابلة للتدقيق فوق نظام Debt Smart Forge الحالي. الدورة لا تمنح النموذج صلاحية مطلقة لتعديل قاعدة البيانات أو النشر على الشبكات الاجتماعية. بدلاً من ذلك، تنتج فحوصات ومهاماً ومسودات، ثم تمرر العمليات المؤثرة عبر موافقة مستخدم ذي صلاحية.

## المكونات الحالية

| المكوّن | الوظيفة | الحالة |
|---|---|---|
| `autonomy_goals` | تعريف أهداف النمو والتحسين والإيقاع | منفذ |
| `autonomy_runs` | حفظ كل دورة تشغيل ونتائجها | منفذ |
| `autonomy_tasks` | تمثيل المقترحات القابلة للتنفيذ | منفذ |
| `content_drafts` | تخزين مسودات المحتوى حسب المنصة | منفذ |
| `autonomy_approvals` | سجل موافقات ورفض مع المراجع والوقت | منفذ |
| `autonomy_metrics` | قاعدة لاحقة لتجميع مؤشرات النمو والجودة | منفذ |
| `/dashboard/autonomy` | مركز القيادة للمشرف والمدير | منفذ |
| `/api/autonomy` | قراءة الحالة وبدء دورة | منفذ |
| `/api/autonomy/approvals` | اعتماد أو رفض المهمة | منفذ |
| `/api/autonomy/publish/preview` | معاينة منشور معتمد دون إرساله خارجياً | منفذ |

## قواعد السلامة

كل دورة جديدة تبدأ بحالة مقترحة أو مكتملة مع `requires_approval=true`. اعتماد المهمة لا يعني نشرها خارجياً؛ فهو ينقل مسودة المحتوى إلى حالة `approved` فقط. يمكن الآن إنشاء معاينة نشر من مسودة معتمدة، وتُرجع المعاينة صراحة أن أي طلب خارجي لم يُرسل. توجد الآن بوابة إيقاف طارئ على مستوى الهدف: عند إيقافها، يرفض النظام أي دورة يدوية أو مجدولة جديدة، مع إبقاء السجلات السابقة متاحة للمراجعة. كما يرفض النظام بدء دورة إذا كانت هناك دورة بحالة `running` لنفس المالك، لمنع التكرار الناتج عن إعادة المحاولة أو استدعاءات الجدولة المتزامنة.

يجب إضافة موصلات المنصات الاجتماعية لاحقاً مع رموز وصول يزودها المستخدم، ومحددات معدل، وسجل نشر، وزر إيقاف مستقل للنشر. لا ينبغي للنظام أن ينفذ تغييرات كود أو تغييرات مالية أو نشرات عامة من دون بوابة موافقة منفصلة.

## ترتيب التوسع

المرحلة التالية هي ربط عامل خلفي موجود مسبقاً في المشروع بتشغيلات الوكيل، ثم إضافة مجدول يومي يقوم بالفحص الصحي وجمع المؤشرات. بعد ذلك تضاف طبقة ذكاء مدمجة لإنتاج محتوى منظم مع تحقق من اللغة والطول والمصادر. بعدها فقط تضاف موصلات النشر لكل منصة على حدة، مع اختبار في وضع المعاينة قبل التفعيل.

## التشغيل المحلي

بعد تطبيق `supabase/20260818_autonomy_control_plane.sql` على قاعدة البيانات، شغّل:

```bash
pnpm typecheck
pnpm smoke
pnpm build
```

ثم افتح `/dashboard/autonomy` بحساب مدير أو مشرف. إذا لم تطبق الترحيل بعد، ستظهر أخطاء قاعدة البيانات عند فتح المسار، وهذا متوقع إلى أن تُطبّق الجداول الجديدة.
